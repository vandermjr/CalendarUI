Calendar / Calendar Grid

Calendar Grid

The main area where time ranges and events are represented visually.

Week

A Week is a horizontal unit of the Calendar Grid. Unlike Week Row, which belongs to the Mini Calendar, Week describes a week in the main grid.

Event Segment

When an Event crosses more than one Week in the Calendar Grid, its visual representation is divided into Event Segments.

Example
Event 16 ───────────────────────────────────────── 29 Calendar Grid Week 1 16 ─────────── 19 ← Event Segment Week 2 20 ───────────────── 26 ← Event Segment Week 3 27 ─────────── 29 ← Event Segment

This is one Event, represented by three Event Segments.

Event Stack

When Events occupy overlapping regions, their visual representations are arranged vertically in an Event Stack.

Example
Week 16 ───────────────────── 20 ← Event A 18 ─────────────────── 22 ← Event B 19 ─────────────── 21 ← Event C Visual stack: ┌─────────────────────────────┐ │ Event A │ ├─────────────────────────────┤ │ Event B │ ├─────────────────────────────┤ │ Event C │ └─────────────────────────────┘
