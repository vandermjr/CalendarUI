When is it used?

CalendarUI

A calendar component library for Avalonia, designed to represent events, selected ranges, and different time-view scales.

What is CalendarUI?

CalendarUI provides a visual structure for navigating dates, selecting ranges, and displaying events inside a calendar grid.

What is it for?

It can serve as a foundation for applications that need to present time-based information clearly, while allowing the consuming application to define its own events and usage rules.
