Events / Event

Event

Represents a time period supplied by the application to be displayed in the calendar.

Event and Event Segments

An Event can cross several Weeks in the Calendar Grid. Its visual representation is then composed of an Event Segment in each required grid region.

Example
One Event: 16 ───────────────────────────────────────── 29 Grid representation: Week 1 16 ─────────── 19 Week 2 20 ───────────────── 26 Week 3 27 ─────────── 29

Event Stack

Events occupying overlapping regions can be positioned at different levels of the Event Stack so that their representations remain visible.

ImportantAn Event Segment is a visual representation of part of an Event. It is not an independent Event.
