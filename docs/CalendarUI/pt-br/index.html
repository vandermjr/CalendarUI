CalendarUI

Uma biblioteca de componentes de calendário para Avalonia, projetada para representar eventos, períodos selecionados e diferentes formas de visualização de tempo.

O que é o CalendarUI?

O CalendarUI fornece uma estrutura visual para navegar por datas, selecionar intervalos e visualizar eventos dentro de uma grade de calendário.

Para que serve?

Ele pode ser usado como base para aplicações que precisam apresentar informações temporais de forma clara, permitindo que a aplicação consumidora defina seus próprios eventos e regras de uso.
