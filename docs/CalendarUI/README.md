# CalendarUI Documentation v3

Modular HTML documentation in Portuguese (pt-br) and English (en).

## Structure

- `index.html` — language-independent entry point placeholder
- `pt-br/` — Portuguese documentation
- `en/` — English documentation
- `assets/style.css` — shared visual system

The documentation intentionally uses hierarchy instead of a global terminology table.
Each concept is documented in the part of the CalendarUI where it belongs.

Visual blocks:
- Blue: navigation and primary structure
- Purple: conceptual highlights
- Green: practical examples
- Amber: notes
- Red: important behavior
